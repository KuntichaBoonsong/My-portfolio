Ocean Run — เว็บลงทะเบียนงานวิ่ง

เว็บไซต์ลงทะเบียนงานวิ่งแบบ Responsive พร้อมหน้าจัดการสำหรับแอดมิน

ภาพรวมโปรเจกต์

Ocean Run เป็นเว็บไซต์สำหรับลงทะเบียนเข้าร่วมงานวิ่ง ออกแบบและพัฒนา Front-end ด้วย HTML, CSS และ JavaScript โดยวางโครงสร้างเว็บไซต์ทั้งหมดด้วยตัวเอง ตั้งแต่หน้าลงทะเบียนสำหรับผู้ใช้งานทั่วไป ไปจนถึงหน้าจัดการสำหรับแอดมิน เน้นออกแบบ UI/UX ที่ใช้งานง่ายและ Responsive รองรับทุกขนาดหน้าจอ

Ocean Run is a running event-registration website. I designed and developed the front-end using HTML, CSS, and JavaScript — planning the full site layout myself, from the public registration flow to the admin management page, prioritizing clean, user-friendly UI/UX across device sizes.

ไฮไลต์การทำงาน

  • ออกแบบและพัฒนา Front-end เว็บไซต์ลงทะเบียนงานวิ่งแบบ Responsive Designed and developed a responsive event-registration website front-end using HTML, CSS, and JavaScript
  • วางโครงสร้างเว็บไซต์ทั้งหมดตั้งแต่ต้น Planned the full site layout from scratch
  • สร้างหน้าจัดการสำหรับแอดมิน โดยเน้น UI/UX ที่ใช้งานง่ายในทุกขนาดหน้าจอ Built the admin management page, prioritizing clean, user-friendly UI/UX across device sizes
