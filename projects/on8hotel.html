On8hotel — Hotel Reservation Website

เว็บไซต์จองห้องพักโรงแรม พัฒนาด้วย PHP เชื่อมต่อฐานข้อมูล

บทบาท: Full-Stack Developer (เน้น Front-End) ทีม: โปรเจกต์กลุ่ม / งานวิชาการ ปี: 2026
PHPMySQLHTMLCSSJavaScript

ภาพรวมโปรเจกต์

On8hotel คือเว็บไซต์สำหรับจองห้องพักโรงแรม พัฒนาด้วย PHP เชื่อมต่อกับฐานข้อมูล MySQL เพื่อจัดการข้อมูลห้องพัก และการจอง ในโปรเจกต์นี้ฉันทำหน้าที่เป็น Full-Stack Developer โดยรับผิดชอบหลักในส่วน Front-End ของระบบ ควบคู่ไปกับการเชื่อมต่อข้อมูลฝั่ง Backend

On8hotel is a hotel reservation website built with PHP, connected to a MySQL database to manage room and booking data. On this project I worked as a Full-Stack Developer, primarily responsible for the front-end while also contributing to the backend data connections.

ไฮไลต์การทำงาน

  • ออกแบบและพัฒนาหน้าเว็บฝั่ง Front-End สำหรับระบบค้นหาห้องพัก แสดงรายละเอียดห้อง และฟอร์มการจอง Designed and developed the front-end pages for room search, room details, and the booking form
  • เชื่อมต่อฝั่ง Front-End กับฐานข้อมูลผ่าน PHP เพื่อดึงและบันทึกข้อมูลการจอง Connected the front-end to the database via PHP to fetch and record booking data
  • ร่วมพัฒนาในบทบาท Full-Stack ดูแลทั้งส่วนหน้าเว็บและการเชื่อมต่อข้อมูลกับฐานข้อมูล Contributed as a Full-Stack Developer, covering both the front-end and database connections
