ภาพรวมโปรเจกต์

One Moby เป็นโปรเจกต์ capstone ระดับมหาวิทยาลัยที่ร่วมงานกับลูกค้าองค์กรจริง โดยฉันได้ร่วมออกแบบระบบ Competency Assessment แบบครบวงจรให้กับ 1Moby ตั้งแต่การประเมินผลแบบ 180° การวิเคราะห์ช่องว่างทักษะ (Gap Analysis) การสร้างแผนพัฒนารายบุคคล (Individual Development Plan) แบบอัตโนมัติ ไปจนถึงโมดูล LMS ที่มีองค์ประกอบรูปแบบ Gamification เพื่อสร้างแรงจูงใจในการเรียนรู้

One Moby is a university capstone project partnered with a real corporate client. I helped design an end-to-end Competency Assessment system for 1Moby — from 180° evaluation and gap analysis, to auto-generated Individual Development Plans (IDP), and a gamified LMS module to drive learning engagement.

โปรเจกต์นี้ยังอยู่ระหว่างการพัฒนา ปัจจุบันทีมฉันกำลังดำเนินการต่อในส่วน Backend ของระบบ

This project is still in progress — my team is currently continuing development on the system's backend.

ไฮไลต์การทำงาน

  • ออกแบบ System Architecture Flow แบบครบวงจร (assessment → gap analysis → IDP → LMS → rewards) Designed the full system architecture flow (assessment → gap analysis → IDP → LMS → rewards)
  • ร่วมพัฒนาในส่วน Front-End ของระบบ Contributed to front-end implementation
  • ทำวิจัยผู้ใช้ (User Research) ด้วย Persona และ Journey Mapping เพื่อออกแบบระบบให้ตรงกับความต้องการจริง Conducted UX research (personas, journey mapping) to ground the system design in real user needs
  • ออกแบบแนวคิด Gamification สำหรับโมดูล LMS (Points, Skills, Missions, EXP) และปัจจุบันกำลังพัฒนาต่อในส่วน Backend Designed the Gamification concept for the LMS module (Points, Skills, Missions, EXP) and currently continuing development on the backend
