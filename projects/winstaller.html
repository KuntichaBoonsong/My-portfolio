Winstaller — WordPress Platform

ระบบจัดการการแข่งขันบน WordPress พร้อมโครงสร้างข้อมูลและระบบสิทธิ์ผู้ใช้แบบ Role-Based

ภาพรวมโปรเจกต์

Winstaller เป็นระบบจัดการการแข่งขันที่พัฒนาและดูแลบน WordPress hosting (InfinityFree) ในบทบาท Backend Developer ฉันออกแบบโครงสร้างข้อมูลการแข่งขันด้วย CPT UI และ ACF พร้อมระบบสิทธิ์ผู้ใช้แบบ Role-Based (Ultimate Member, User Role Editor) และดูแลความปลอดภัยรวมถึงการสำรองข้อมูลของระบบ

Winstaller is a competition management system developed and maintained on WordPress hosting (InfinityFree). As Backend Developer, I designed the competition data structure using CPT UI and ACF, built a role-based access system (Ultimate Member, User Role Editor), and maintained system security and backups.

ไฮไลต์การทำงาน

  • พัฒนาและดูแลระบบบน WordPress hosting (InfinityFree) Developed and maintained the system on WordPress hosting (InfinityFree)
  • ออกแบบโครงสร้างข้อมูลการแข่งขันด้วย CPT UI และ ACF พร้อมระบบสิทธิ์ผู้ใช้แบบ Role-Based Designed the competition data structure using CPT UI and ACF, along with a role-based access system (Ultimate Member, User Role Editor)
  • ดูแลความปลอดภัยและสำรองข้อมูลของระบบด้วย Wordfence, WP Activity Log และ UpdraftPlus Maintained system security and backups using Wordfence, WP Activity Log, and UpdraftPlus
